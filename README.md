# Just Intonation vs. Equal Temperament

A small macOS desktop listening demo that compares 12-tone equal temperament (12-TET) with fixed C-major just intonation (JI). It uses one low-latency audio stream, so any of the eight chords can play together without stopping the others.

## Install and run

Tkinter is included with the standard Python installers from [python.org](https://www.python.org/downloads/macos/). In Terminal:

```bash
cd just-intonation-demo
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python3 main.py
```

If macOS asks for microphone/audio permissions, allow the app or Terminal to use the audio device. Choose the desired output device in macOS Sound settings before launching.

## Use

Each of the eight buttons is an independent latch. Press a button to play that row's tuning of the chord; press it again to release that chord. Enable the two C-major buttons together to hear the small interval differences and beating. `Stop All` releases every active voice.

The master volume applies to the final mixed signal. The `Organ-like overtones` check box switches between a harmonic organ-style sound and pure sine waves; it affects both tuning systems equally.

## Tuning and voicings

12-TET uses A4 = 440 Hz and `440 * 2 ** ((midi_note - 69) / 12)`. Fixed JI is referenced to C4 = 261.625565 Hz with C-major ratios C 1/1, D 9/8, E 5/4, F 4/3, G 3/2, A 5/3, and B 15/8. JI pitches are fixed by note and octave, never retuned by the chord currently playing.

The C4 value generated by the exact 12-TET A4=440 formula is 261.6255653006 Hz, the supplied C4 reference rounded to six decimal places.

The chord voicings are C4–E4–G4, A3–C4–E4, F3–A3–C4, and G3–B3–D4.
